### Settle a project that changed on both sides

**Added**
- When a project linked to git changed both here and on the remote, **Pull** joins the two when git can, saving a
  version that holds both. When it cannot, nothing is changed and the GIT card offers three ways, each keeping both
  sides as versions so nothing is lost: **Keep mine** (their side becomes a version, yours the newest on top), **Take
  theirs** (theirs becomes the newest version, yours the one before it) and **Compare...**, which opens the Compare card
  with your newest version against their side before you choose.
