### The synth's keyboard lights every key you hold

**Changed**
- In TestingPlaygroundSynth, a panel's keyboard now lights every key that is down, whoever plays it: your MIDI
  keyboard or the DAW's notes, the panel's own keys and a racing wheel's start key, in the same colour a click on a key
  gives it. A note the sustain pedal holds after you let go of its key goes dark with the key.
